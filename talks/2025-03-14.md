The standard GF language has only a limited support for type inference, and it doesn't support polymorphism. This means that the programmer has to write a lot of type signatures or manually instantiate type arguments. On the other hand, the language has
function overloading. If we want to have better type inference and add polymorphism while keeping the function overloading, then a single source program can be refined to several type-correct programs. This interacts in an interesting way with the nondeterminism
built into the language.
