title: Scheduling Synchronous Control Software by Solving Constraints

Embedded control software is often specified as a set of periodic tasks
together with a dependency graph describing their communications via shared
variables. This talk will describe an ongoing collaboration with Airbus to
express such systems in a specialized version of the Lustre programming
language. Our version of Lustre is “rate synchronous” in that components are
synchronous relative to their respective rates, but not necessarily
simultaneous relative to the base period.

The compilation of these programs uses Integer Linear Programming (ILP) to
assign individual tasks to specific phases under requirements on load
balancing, resource limiting, and end-to-end latency. Recently, we have been
trying, so far with mixed success, to extend this work to generate multiple
threads of execution. To this end, we have been experimenting with different
ideas, refactoring our compiler, and using Google's CP-SAT solver to attack
increasingly complex constraint problems.
