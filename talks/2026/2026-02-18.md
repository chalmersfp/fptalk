Between 2015-2019 I had VR project called MUSTE, which could mean "Multilingual syntactic text editing" or "Multimodal semantic text editing" (or something in that vein). The project financed a PhD student, Herbert Lange, and together we created a prototype for a "language learning game" (called MULLE, "MUSTE Language Learning Environment"). 
Herbert used this to build an exercise tool for learning Latin, and we came up with ideas for how to semi-automatically generate exercises. The main problem with MUSTE and MULLE was that you need to create a grammar for your exercises, and there are very few (if any) language teachers who know how to write a formal grammar. Herbert and myself and Koen had some ideas how to try to solve this, but then the project funding dried up, Herbert graduated and moved, and none of us had the time to continue the work so nothing more has been done.
Now it's six years later, and I still think that the project is interesting, but maybe not for language learning. Probably you would need to incorporate AI and statistical NLP to develop a good pedagogical language learning tool. So, let's change the setting instead. Programming languages are much more suited for formal grammars, because they need to be unambiguous - and they always have some formal abstract syntax, and corresponding semantics. All things that MUSTE made use of. Maybe it's possible to use the underlying ideas (abstract/concrete syntax, and visual editing) to develop a "programming learning game", or a "visual programming language", or something in that vein.
In this seminar I will present the basic ideas of MUSTE, show a 10-year old demo (that's still working!), and outline some ideas for how to adapt this to programming language education.
