One of the nice things about high level data parallel programming is
that you can revisit a lot of old or trivial problems and suddently they
become exciting again. In this talk I will talk about the problem of
"unparsing" or "pretty printing", where given a tree we have to produce
its text representation, in both fully parallel and practically
work-efficient manner. It turns out this can be done in fairly nice ways
using techniques such as flattening-by-expansion and Tarjan/Vishkin's
Euler tour technique. Whilst the practical need for massively parallel
tree-printing is perhaps not so great, it is an interesting case study
for various parallel programming techniques for handling problems that
don't look so parallel at first glance.
