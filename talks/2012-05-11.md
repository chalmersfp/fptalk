title: "Data Serialisation in Haskell - an orthogonal approach based on the Eden runtime"
place: "3364"
date: 2012-05-11 14:15:00

(based on a paper [1] presented and published in IFL 2010)
-----------------------------------------------------------------
Departing from our vast experience in implementations of parallel
Haskell dialexts on distributed memory platforms, we discuss the
data serialisation of the Eden runtime system. Factoring out this
serialisation as a separable feature, we are able to outline its
potential applications for Haskell in general, apart from
implementing parallelism constructs.
The particular approach to serialisation of Haskell data
structures which we take here provides a high degree of
flexibility, highly desirable and so-far unrivalled properties:
it is truly orthogonal to evaluation and does not require any
type class mech- anisms. Especially, (almost) any kind of value
can be serialised, including functions and IO actions. We outline
the runtime support on which our serialisation is based, and
present different versions of the wrapper code in Haskell which
can ensure type safety of the serialisation process. Furthermore,
we demonstrate that our serialisation offers several applications
which cannot be realised using any other existing approaches.
