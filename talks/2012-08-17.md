speaker: "Kazutaka Matsuda"
title: "Deriving Pretty-Printers"
place: "3364"

When one implements a programming language, it is usual that he/she
also implements a parser and a pretty-printer. However, manually
writing both parser and pretty-printer is not only tedious---for
example, if one changes the syntax, he/she must reflect the change to
both programs, but also error prone---it is possible that an
output of pretty-printer is not parsable, i.e., not in a valid syntax.

Towards the problem, we propose a method based on inverse computation
to produce a parser from an invertible pretty-printer. Specifically,
we use a DSL to write a pretty-printer, and derive a parser from the
pretty-printing program by inverse computation.  A technical
contribution is fitting the problem to the usual inverse computation
problem; a naive solution would fail because of the information
mismatch between a pretty-printer and a parser: A pretty-printer does
not know non-pretty but parsable strings, but a parser does not know
what a "pretty" string is. Thus, some additional information is
required to fill the gap. Our DSL provides a concise way to encode
this "additional information" to pretty-printers.

In addition to pretty-printer and parser, there are a lot of examples of
round-trip programs with this kind of information mismatch. An important
one is a pair of a compressor and decompressor. Sometimes, there are
many compressed strings corresponding to a uncompressed string in some
compression methods such as runlength encoding and LZSS, and it is
expected that a decompressor can decompress all of the such compressed
strings while a compressor returns an appropriate compressed one.  We
hope that this research would be a first step towards connecting the exiting
results of inverse computation to construction of such round-trip programs
with the "information mismatch".
