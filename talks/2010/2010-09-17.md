speaker: "Jonas Almström Duregård"
title: "Extending Haskell's syntax using LBNF grammars"
place: "EDIT room"
date: 2010-09-17 10:15:00
---
I present a library for embedding (Labelled) BNF grammars in Haskell
modules. Like the BNF Converter (BNFC), the library generates parsers
and abstract syntax data types for specified languages (object
languages).

By using a Haskell extension called quasi-quotation, the grammars can
be written in ordinary LBNF syntax inside Haskell code. By using
Template Haskell, code generation can be performed directly by the
Haskell compiler. This eliminates the need for a two-staged compilation.

Another feature of the library is the automatic generation of
quasi-quoters for the object language. This means that sentences in the
object language can be used as Haskell expressions, and the compiler
will automatically replace them by their abstract syntax
representations.

It turns out that anti-quotation is a key feature in making usable
quasi-quoters. Anti-quoting lets a user put Haskell expressions inside
sentences of the object language, so that these injected expressions
define parts of the resulting abstract syntax.
