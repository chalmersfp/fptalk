speaker: "Koen Claessen"
title: "Testing Implementations of Search and Optimization Algorithms (using contrapositive testing, inductive testing and co-inductive testing)"
place: "8103"
date: 2013-04-26 10:00:00
---
Shortest path finding, SAT solving, automatic theorem proving, model
checking, (integer) linear programming; these are all examples of
problems that require complex algorithms and even more complex
implementations to be solved. How can we effectively *test* these
implementations? Automatic testing demands an executable
specification, but in these cases, an executable specification is
either as complex as the implementation we are testing (and is thus
not trustworthy), or runs too slow (and is thus impractical).

In this talk, I will present a number of alternative testing methods,
which are actually inspired by commonly used proof techniques. The
result is a range of techniques that can be used to create complete,
testable specifications for search and optimization algorithms that
are yet efficient and practical. The techniques are called
contrapositive testing, inductive testing, and co-inductive testing.
