speaker: "Christian Schlyter"
title: "Visualization of a Finite First Order Logic Model"
place: "8103"
date: 2013-03-20 13:00:00
---
Creating visualizations of finite first order logic models can be very
beneficial for users studying the models as it provides an additional
aid for the user and makes it easier for the user to understand and
comprehend the model. This thesis describes methods on how to
visualize the different parts of the model, the domain, functions and
predicates, and then combining them into a drawing for the user to
look at. We will also provide methods on how to reduce a model using
function and predicate properties in order to simplify the drawings we
make of a model.
