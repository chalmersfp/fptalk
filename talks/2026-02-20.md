Developing formal grammars is a time-consuming process, which often requires proficiency in the target language. At the same time, annotated corpora such as Universal Dependencies already encode grammatical information implicitly.

In this talk, we present a method for the automatic generation of a subset of Resource Grammar Library (RGL) modules in Grammatical Framework (GF). Our approach infers the concrete implementations of functions specified in the GF abstract syntax by learning from corpus data. Guided by types of function arguments, we use decision trees to model the syntactic rules. The resulting system enables automatic construction of RGL components directly from annotated data.
