title: "Towards a Programming Language based on Classical Linear Logic"
place: "EDIT 3364"
date: 2013-11-22 10:00:00
---
It has long been expected that Classical Linear Logic (CLL) should be the
foundation of concurrent programming, as System F is the logical foundation of
functional programming. However, so far, few programming languages have
integrated this idea, even in the academic world.

We have made steps towards designing such a language.  We show how to capture
the concurrent features of CLL in System F by using continuations, which sheds
a new light on crucial features of CLL such as duality and the par operator.
The System F interpretation is practical enough to be used to embed the new
programming into Haskell.
