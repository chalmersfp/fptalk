speaker: "Michał Pałka"
title: "Generating random test data satisfying predicates using narrowing"
place: "EDIT 3364"
date: 2013-12-06 10:00:00
---
We present an approach to generating random data satisfying a given
predicate using narrowing. Generating random values that satisfy a
predicate often requires writing complex ad-hoc generators and make it
difficult to predict the distribution of the generated values, which
could possibly result in poor test coverage. Instead, our generator
needs a simple algebraic data type definition, and a Haskell boolean
function that defines the predicate. The values can be generated with
uniform distribution, or its uniformity can be traded for increased
performance.

We leverage the laziness of predicates defined in Haskell to perform an
efficient searches for values satisfying them. For achieving uniform
distribution we use a technique for computing cardinalities of all
values of algebraic data types to guide the random search.

We apply the generator to generate simply-typed lambda terms (with
polymorphic constants) for testing the GHC compiler for optimiser bugs
and evaluate the results against a hand-written generator.
