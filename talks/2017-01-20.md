We present SpecCheck, a simple monadic specification language
for property based testing of concurrent systems. We present an approach to
specification making use of elementary results from session types which allows
one specification to be used as a test oracle and a mockup for both client
and server code. We also show how we can discover inconsistent SpecCheck
specifications.
