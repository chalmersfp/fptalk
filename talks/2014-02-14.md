I'm going to give an introduction to a framework for functional, high
performance arrays called Mathematics of Arrays (MoA), developed by Lenore
Mullin. MoA is intended for calculating arrays in a style similar to the
Bird-Meertens formalism for lists. Once a calculation is complete the resulting
program is normalized, first into Denotational normal form, and then into an
Operational normal form, which is efficiently implementable.

MoA has a strong focus on arrays of higher dimensions and central to working
with them is the ψ-function and its associated calculus. Dimensions are used to
map array computations to different levels in the memory hierarchy. For
instance, some of the lower dimensions of an array might be mapped to local
memory while higher dimensions. In order to give the programmer control over
how to access the memory hierarchy there is the process of Dimension Lifting. It
reshapes a multi dimensional array to explicitly add dimensions.

MoA is very relevant to the work on high performance arrays done here in the FP
group. In particular there is a strong correspondence between denotational
normal form and pull arrays.  I have yet to figure out the exact relation
between MoA and pull- and push arrays and I hope to get some feedback on how to
understand it better.
