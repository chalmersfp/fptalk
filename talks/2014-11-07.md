Wouldn't it be nice if, given the definition of a function

f : A -> B   ,

we could automatically generate its inverse of type

f_inv : B -> Set A   ?

I have recently been working on such a method. In this talk, I will show you
how it works, and discuss applications.

The main motivation for the work is when "Set a" is implemented as an effective
random generator of elements of type "a". Then, we can for example take a
predicate:

isSearchTree : Tree A -> Bool

and automatically construct a test data generator for search trees thus:

arbSearchTree : Set (Tree A)
arbSearchTree = isSearchTree_inv True

All this is work in progress, comments are very welcome.
