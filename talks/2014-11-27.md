speaker: "Baltasar Trancón Widemann"
title: "Declarative Data Stream Programming with Sig"
place: "8103"
date: 2014-11-27 10:00:00
---
Sig is the prototype of a purely declarative programming language and
system for the processing of discrete, clocked synchronous,
potentially real-time data streams.  It aspires to combine good static
safety, scalability and platform independence, with semantics that are
precise, concise and suitable for domain experts.  The design of Sig
covers a middle ground between the data-flow diagram paradigm favored
by domain experts, and the functional reactive paradigm favored by
academics.  Applications range from reactive systems, embedded in a
context with user input devices, sensors or communication channels, to
processors and generators of time-series data, such as audio signals
or dynamic simulations in numerous branches of science, engineering
and digital arts.  The current state of the Sig system comprises a
core language with formal denotational semantics, transformations from
both functional-style and diagrammatic frontend notations, and a
Java-based prototype compiler and execution environment.  The talk
gives an overview of the design, lessons learned from its
implementation, and present and future application case studies.
