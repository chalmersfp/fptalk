speaker: "Jurriaan Hage"
title: "Security Type Error Diagnosis for Higher-Order, Polymorphic Languages (presented at PEPM 2013)"
place: "EL43"
date: 2013-02-26 10:00:00
---
We combine the type error slicing and heuristics based approaches to type error
diagnostic improvement within the context of type based security analysis on a
let-polymorphic call by value lambda calculus extended with lists, pairs and
the security specific con- structs declassify and protect. We define and
motivate four classes of heuristics that help diagnose inconsistencies among
the constraints, and show their effect on a selection of security incorrect
programs.
