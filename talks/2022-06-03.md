Have you ever wondered how a compiler like GHC maps high-level functional constructs like algebraic data types, lazy evaluation, or automatic memory management into code that runs on your computer? Good news, you're not alone, and this talk is for you! As part of the ongoing Ph.D. course on runtime systems, we implemented an interpreter and a compiler for a simple lazy functional language based on the tutorial book by Simon Peyton Jones and David Lester [1]. This tutorial revolves around compiling functional code into sequential one that runs on the abstract Three Instruction Machine (TIM) [2]. Our interpreter implements the TIM in Haskell, whereas the compiler produces C/LLVM code that gets linked against a small runtime system written in C.
In this talk, we will discuss the most interesting aspects of the project so far: how the Three Instruction Machine works; and how we implemented it both in Haskell and C.
[1] Implementing functional languages: a tutorial. David R Lester, Simon L Peyton Jones. Published by Prentice Hall | January 1992
[2] J. Fairbairn and S. C. Wray TIM: a simple abstract machine for executing supercombinators Proceedings of the Functional Programming and Computer Architecture Conference, Portland, Oregon, September 1987.
