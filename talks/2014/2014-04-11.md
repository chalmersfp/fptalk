In this talk I will introduce Haste.App a new Haskell-based programming model for web applications, allowing one to write client-server web applications as a single program as opposed to the traditional approach of writing client and server as two separate entities. This gives us the benefit of type safety across the network boundary, as well as a reduction in the amount of boilerplate communication code that needs to be written.

The web is quickly becoming the de facto standard platform for large scale software development, but the available tools and techniques are not keeping pace. While most web applications are conceptually a single entity, they are commonly implemented as two separate, largely unrelated programs communicating via ad hoc network protocols. Javascript, with its weak typing and universally acknowledged problems, powers the client part of most web applications, making the web fertile soil for all manners of bugs.

Building web applications using Haste.App lets us partake of the web's many advantages - ubiquity, platform independence, ease of deployment - while retaining our favorite features from the world of traditional software development.
