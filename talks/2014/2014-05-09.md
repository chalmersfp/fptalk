place: "EDIT-room"

I will show how to achieve efficient evaluation for an untyped
representation of expressions. By efficient, I mean that there is
"almost" no tag checking of interpreted values. Normally, this involves
defining a separate type-indexed version of the expression data type.
The twist of this work is to avoid this extra type by using a single
generic representation of type-indexed expressions. The technique lends
itself particularly well to an open compositional implementation, and
this is also where we see the highest performance gains -- more than 5x
in common cases.

This work will be presented at TFP 2014.
