title: "Type- and Example-Driven Program Synthesis"
place: "EDIT Room"
date: 2014-10-06 10:00:00
---
In this talk I will describe some ongoing work in which we're
attempting to synthesize recursive programs that process ML-style
algebraic datatypes. Following previous work on inductive program
synthesis, we draw on ideas from proof theory to enumerate well-typed
programs that satisfy a given set of input--output examples. I'll
demonstrate our prototype implementation of these ideas, which can
successfully synthesize functions like 'fold' over lists from just a
few examples.

This is joint work with Ph.D. student Peter-Michael Osera, and
supported in part by the NSF ExCAPE project.
