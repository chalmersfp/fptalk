---
speaker: "Nikita Frolov"
title: "Decomposing Schedules of Recursive Programs"
place: "8103"
date: 2014-04-24 10:00:00
---
Hardware more capable of parallel execution means that more program scheduling
decisions have to be taken to utilize that hardware efficiently.  To this end,
compilers implement coarse-grained loop transformations in addition to
traditionally used fine-grained instruction reordering.  We show how these
transformations can be applied to recursive combinators in shallowly embedded
languages. First, we define generic recursive combinators indexed by their tiles
in a universe of algebraic datatypes. Implementation of tiling as function
ornament gives a proof of its naturality for free. Second, we show how
composition of tile indices can be used to define orders of computation of
recursive combinators with varying granularity.
