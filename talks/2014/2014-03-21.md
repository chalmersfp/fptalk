Debugging Haskell crashes is often difficult, because there is no error
reporting that help you find the bug. Usually the programmer only sees "head:
empty list". This master thesis is examining one way of implementing stack
traces for GHC. The implementation aims to have as little run time cost as
possible by utilizing the GHC stack. In this presentation we will see demos,
the Haskell-land interface (think catchWithStack) and look at the relevant
details of how GHC compiles Haskell code and its run-time system.
