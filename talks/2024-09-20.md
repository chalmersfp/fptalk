title: "System-level Functional Programming with Linear Types"
place: "Analysen"

---
Functional programming languages are generally considered high-level,
abstracting away underlying architectural details. This talk proposes
a functional language suitable for system-level programming (SLFL).
SLFL is derived by defunctionalizing polarized linear logic. Compared
to traditional system languages like C or assembly, SLFL retains
strong typing and the Curry-Howard correspondence with logic. This
makes it a promising intermediate language for strongly-typed
compilers. For scenarios requiring greater control, programmers could
utilize SLFL directly. In fact, type annotations in critical places
might suffice.
